总经理团队 · 独立版
================================

【启动】双击「启动.bat」,浏览器会自动打开 http://127.0.0.1:8787
(也可以先运行 server.js 所在目录下的「启动.bat」,再手动打开浏览器)

【两种用法】
1. 演示模式(默认勾选):不需要任何 Key,直接输入任务点「下达任务」,
   即可看到完整的团队协作流程(内容为拟真演示数据)。
2. 真实运行:在「设置」里填入 OpenAI 兼容接口的三项信息,取消勾选演示模式:
   - API 地址:平台文档给出的 Base URL(如 https://api.deepseek.com)
   - API Key:你在对应平台申请的密钥
   - 模型名:如 deepseek-chat、glm-4-flash、moonshot-v1-8k 等
   兼容 DeepSeek、智谱GLM、Kimi、通义、OpenAI 及各类中转站。

【隐私】任务数据只在你的电脑上处理;API Key 只保存在浏览器本地,不会上传。
【成果】每次任务的成果文件保存在 app\成果\ 目录下,按任务分文件夹。

【常见问题】
- 提示"接口返回 HTTP 401":API Key 不对。
- 提示连接超时:检查 API 地址是否正确、网络是否能访问该平台。
- 提示"HTTP 402 / 余额不足":去对应平台充值。
- 端口被占用:用记事本打开 server.js,把开头的 8787 改成其他数字。
- 关闭服务:右键任务栏的「GM-Team Server」窗口关闭,或在窗口里按 Ctrl+C。
